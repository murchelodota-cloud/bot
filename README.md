# Саррочка — пикми-бот-модератор для Telegram

Модерация, «масса» (репутация), преды со сгоранием, суд чата, антирейд с капчей,
настроение и три стиля общения (pickme / strict / normal).

## Что нужно

1. **Python 3.11+** (проверить: `python --version`).
2. **Токен бота** — напиши @BotFather → `/newbot` → скопируй токен.
3. В @BotFather для этого бота:
   - `/setprivacy` → **Disable** (иначе бот не видит обычные сообщения в группе и масса не считается).
   - `/setcommands` → вставь список из `commands.txt` (необязательно, но удобно).
4. **Свой user_id** — напиши @userinfobot, он покажет.
5. Добавь бота в чат и сделай **админом** с правами: удалять сообщения, блокировать пользователей,
   приглашать (для капчи/ограничений).
6. (Опционально) для `/report` — создай приватный канал/чат для админов, добавь туда бота,
   узнай его id (перешли сообщение из него в @userinfobot или @getmyid_bot) и впиши в `REPORT_CHAT_ID`.

## Запуск

```bash
cd lika_bot
python -m venv venv
# Windows: venv\Scripts\activate     Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env
# открой .env и впиши BOT_TOKEN, OWNER_IDS
python main.py
```

Чтобы бот работал круглосуточно, нужен сервер (любой дешёвый VPS) — там же `python main.py` под
`systemd`/`screen`, либо Docker:

```bash
docker compose up -d --build
```

## Команды

| Команда | Кто | Что |
|---|---|---|
| `/warn [причина]` (ответом или @user) | админ | пред; вес зависит от массы цели, сгорает через N дней; авто-мут/бан по порогам |
| `/unwarn`, `/warns` | админ / все | снять преды / посмотреть |
| `/mute 30m|2h|3d`, `/unmute` | админ | мут |
| `/ban [причина]`, `/unban`, `/kick` | админ | бан / разбан / кик |
| `/court` (ответом или id) | админ | голосование за разбан, голоса взвешены по массе |
| `/report` (ответом) | все | жалоба в REPORT_CHAT_ID с кнопками «мут 1ч / бан / игнор», сообщение с командой удаляется |
| `/remind 2h текст` | все | напоминание (30m / 2h / 3d), переживает перезапуск бота |
| `/tag add имя` (ответом на стикер), `/tag del имя` | админ | сохранить / удалить стикер-тег чата |
| `/tag имя`, `/tags` | все | прислать стикер по тегу / список тегов |
| `/me`, `/top` | все | карточка, топ по массе |
| `/thanks`, `/mood` | все | сказать спасибо (+настроение), узнать настроение |
| `/style pickme|strict|normal` | админ | стиль ответов |
| `/settings [ключ значение]` | админ | пороги предов, дни сгорания, антиспам, антирейд… |
| `/digest` | админ | дайджест вручную (авто — раз в неделю) |

## Как это устроено

- `phrases.py` — все реплики. Хочешь поменять характер — правь только его.
- `config.py` — числа: сколько массы за что, пороги по умолчанию.
- `db.py` — SQLite (`lika.db` рядом с ботом). Для большого числа чатов можно перенести на PostgreSQL.
- `handlers/` — модерация, суд, антиспам, профиль, общее.

Масса: +1 за сообщение (не больше 40 в день), +6 за реакцию на сообщение Саррочки, −15 за пред.
Настроение Саррочки падает на 1 в час без внимания, растёт от `/thanks` и реакций; ниже 30 — вздыхает.

Дополнительно: мат-фильтр с мягким режимом (предупреждает, не удаляет) — `/settings matfilter 1`,
`/settings mat_soft 0` для жёсткого; резка одинаковых сообщений подряд (`dupfilter`);
ежедневный «вопрос дня» (`qotd`). Всё включается/выключается через `/settings`.

## Музыка (следующий этап)

Для проигрывания в видеочате группы нужен отдельный **пользовательский аккаунт** (userbot) + `py-tgcalls`
и `yt-dlp`, потому что обычный бот не может войти в голосовой чат. Это добавляется отдельным модулем.
